# Demo Script — Flowboard (4 минуты)

1. **Landing** (20с) — «Ship projects, not chaos», градиентные пятна.
2. **Board** (80с) — главный экран:
   - Перетащить «Billing page redesign» из In Progress в Review
   - Показать карточки: приоритет-точки, метки-чипы, счётчики подзадач/комментариев, аватары
   - Фильтр по исполнителю
3. **Dashboard** (40с) — мои задачи, прогресс проектов (API v2 at risk — жёлтый), лента активности.
4. **Projects** (30с) — карточки с прогрессом; создать проект вживую.
5. **Team** (40с) — velocity по спринтам, workload-балансировка (stacked bars).
6. **AI Planner** (60с) — вау-момент:
   - Feature → Decompose → 6 подзадач с оценками и суммой часов
   - Goal → Generate Plan → timeline фаз с вехами
   - «Mock mode — работает без ключей»
7. **Финал** (10с) — тёмная тема, мобильный вид доски.
